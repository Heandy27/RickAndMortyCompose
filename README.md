# Rick and Morty – Android App (Jetpack Compose)

**Rick And Morty** Rick And Morty App is an app created with Jetpack Compose that allows you to view information about the characters from the Rick and Morty series. The app connects to a REST API to fetch data about the characters and displays it interactively.

## 📱 Features

- **Characters List Grid:** Organizes views in an orderly manner into rows and columns.
- **Character Details:** Dedicated detail screen (supports rich content and external links).
- **Offline Support (Room):** Persist characters on device.
- **Modern Navigation (NavHost):** Smooth navigation between screens in Compose.
- **MVVM:** Clear separation of UI, state, and business logic.
- **Dependency Injection (Hilt):** Clean, scalable DI setup.
- **Networking (Retrofit):** Connects to a REST API backend.
